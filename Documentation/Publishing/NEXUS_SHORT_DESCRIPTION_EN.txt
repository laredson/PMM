Palworld Manager Merger (PMM)

MAKE CONFLICTING PALWORLD MODS WORK TOGETHER.

Scan -> Merge -> Play.

PMM analyzes your PAK mods, keeps the originals intact, and creates only the compatibility patch needed when mods edit the same content. If two mods genuinely want different values, PMM asks which result you want instead of blindly overwriting one mod.

INSTALL
Extract anywhere -> open PMM -> run Start.cmd.
Then: Import -> Analyze -> Build -> Deploy -> Play.

Runtime-tested combinations include MultiJump + FlyMode, Fly + WingPack, Stack/ZeroWeight + Food Never Spoils + Early Aquatic, Easy Breeding + No Collision Farms, and RushRoar Leather Drop v2 + FasterMounts. PMM is not limited to those names; it analyzes the actual files you give it.

If a conflict is not yet supported, PMM can export an AI_HANDOFF ZIP. Give it unchanged to an AI, import the returned PMM_MANUAL_SOLUTION_V1, test it, and optionally export the successful case as a Knowledge contribution.

PMM can also manage/deploy mods and back up worlds, but compatibility merging is its main purpose.

Full documentation, source, AI/developer handoff and manual Knowledge-sharing instructions are included in the download.

OPEN SOURCE / COMMUNITY

Tested Knowledge contributions are especially welcome. The goal is to grow a community library covering as many existing and future mod conflicts as possible.
