# Knowledge Library

## Purpose

`Knowledge/` is the memory of solved compatibility work. It stores:

- exact fixtures and hashes;
- runtime vs structural status;
- known behavior lessons;
- behavior-symbol hints for Semantic Lab.

## What Knowledge may do

- improve labels/explanations;
- identify a known exact fixture;
- provide regression expectations;
- give AI/modders context;
- help developers recognize a reusable structural pattern.

## What Knowledge may not do

It may not say “this filename worked once, therefore accept it forever.” Automatic Build authorization still belongs to production adapters working on the exact current bytes.

## Community contribution model

A useful contribution contains:

- original AI_HANDOFF or reproducible input description;
- exact source hashes when possible;
- returned/manual solution if used;
- runtime PASS/FAIL report;
- game/PMM/mod version context.

Maintainers should generalize the evidence into a reusable proof, not an allow-list.
