# Possible roadmap after 1.0

These are directions, not promises or fixed release dates.

## Compatibility intelligence

- deeper Kismet/Blueprint IR and control-flow/effect analysis;
- dependency-closed semantic change capsules;
- advanced review UI for selecting independent mod behaviors;
- more generic safe adapters derived from community fixtures;
- signed/versioned/community Knowledge packs.

## Mod ecosystem integration

- Nexus Mods connector for search/download/update workflows;
- automated modlists/profiles;
- Steam Workshop support if/when applicable to the target ecosystem;
- PalSchema awareness/integration;
- UE4SS mod awareness/management context;
- Game Pass installation/support path.

## Product hardening

- headless Windows regression runner;
- richer diagnostics export;
- release/update channel for mappings/Core/Knowledge;
- recovery journal improvements;
- easier import/export of complete reproducible PMM workspaces.

## Community development

- one-click Knowledge contribution package;
- documented fixture contribution format;
- maintainer tooling to compare new cases against existing structural lessons;
- AI-assisted mod-development workbench using local game data and PMM's extraction/semantic tools.
