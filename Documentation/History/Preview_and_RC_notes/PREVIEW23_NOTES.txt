PalModMerger preview 23
========================

Runtime contract repair
-----------------------
Preview22 successfully compiled PMMCore 0.6.4 but then rejected it because the
startup guard tried to parse the first textual line from `--version`. On the
reported Windows installation the assembly metadata was correct while that
textual probe returned no usable line.

Preview23 replaces that fragile contract:
- PMMCore is 0.6.5.
- exact AssemblyVersion 0.6.5.0 is the identity check;
- `self-test` is the execution-health check;
- the self-test emits `PMMCORE_SELFTEST_OK 0.6.5`;
- PowerShell searches the complete process output for that marker and checks the
  native exit code; it does not depend on the first output line;
- pmmcore.runtimeconfig.json and pmmcore.deps.json are required before the Core
  is accepted;
- failures now include the complete probe output.

PMMCore remains framework-dependent and is executed through the exact portable
.NET 8.0.424 host selected by setup. No win-x64 runtime-pack restore is needed.

Merge algorithms are unchanged from preview22.
