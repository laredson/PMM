Palworld Manager Merger v1-preview34-RC5

RC5 is a saved-patch deployment state hotfix over RC4.

Fixed
-----
- After selecting "No compatibility patch" and deploying source mods only, selecting a previously saved compatible PMM patch now enables Deploy immediately.
- A fresh Analyze is no longer required merely to deploy a saved patch whose manifest proves exact active source hashes + mappings.
- Analyze remains required to inspect/build a new compatibility plan.

Merge engine
------------
- PMMCore 0.8.1 and all merge adapters are unchanged from RC4.
- Mappings are unchanged.
- Save/restore and deployment transaction logic are unchanged.

Acceptance check
----------------
1. Select No compatibility patch -> Deploy.
2. Select a saved patch that matches the same active sources.
3. Deploy must enable immediately, without Analyze.
4. Deploy it and verify the overlay is restored.
