# Palworld Manager Merger v1.0 — Release Notes

First public release of PMM as both a Palworld PAK mod manager and compatibility merger.

Highlights:

- N-provider compatibility analysis against current Vanilla game data.
- automatic composition of proven independent changes.
- true conflicts resolved at the smallest proven value/property instead of whole-mod winner selection.
- one global PMM compatibility overlay.
- saved compatibility-patch library with radio selection and direct redeploy.
- **No compatibility patch** manager-only mode.
- source-mod import/enable/disable/delete/deploy workflow.
- transactional managed Deploy with backups/hash checks.
- world save backup and restore.
- English and Spanish UI.
- Knowledge Library + Semantic Lab evidence layer.
- self-contained AI_HANDOFF workflow for Unsupported cases.
- complete open-source PowerShell/WPF/C# source and development documentation in the public ZIP.

Runtime-proven examples and exact evidence are documented in `RUNTIME_PROVEN_COMPATIBILITY.md` and `../Knowledge/`.
