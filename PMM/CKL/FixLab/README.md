# Fix Lab Knowledge Layer

Fix Lab repair knowledge is separate from ordinary merge compatibility knowledge.

- `Stable/fix-recipes.json` contains reviewed exact-source repair recipes and output variants.
- `Experimental/` contains candidate knowledge that cannot authorize unattended production output.
- `Cases/<caseId>/` contains compact executable recipes, bounded transformation payloads, evidence and validation reports.

A recipe match is only context until its exact source/reference contract matches. Automatic Repair additionally requires a present native executor, a complete variant recipe, Current Game Reference when required, and successful writer/readback validation.

Case 001 is executable in the native V2 engine. Either exact Gawr Gura v5 Normal or exact FullReplacement independently generates all five documented outputs locally. No repaired PAK fixture or `GawrGura_v7.zip` is part of the product path.
