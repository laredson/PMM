Palworld Manager Merger v1-preview34-RC4

RC4 is a source-validation hotfix over RC3.

What changed
------------
- Fixes the RC3 SmokeTest regex used to detect the invalid Windows PowerShell `((if...)` pattern.
- The previous regex was over-escaped (`\\(\\(if\b`) and .NET Regex interpreted it as an unterminated group.
- RC4 uses the valid pattern `\(\(\s*if\b`.
- The RC3 source-mod enable/disable fix itself is retained unchanged.
- Manager-only / No compatibility patch behavior is retained unchanged.
- PMMCore 0.8.1, merge adapters, mappings, SaveService, PakService, LibraryService and MergeEngine behavior are unchanged.

Runtime acceptance
------------------
1. Fresh RC4 folder -> Import a PAK -> immediately uncheck it before Analyze.
2. It must move to Mods/_Disabled without error.
3. Re-check it and confirm it returns to active.
4. Select No compatibility patch and Deploy source mods only.
5. Optionally select a saved compatibility patch and Deploy it again.
