# Release page checklist

Before publishing 1.0:

- [ ] Replace preview/RC wording with final v1.0 wording.
- [ ] Add final file SHA-256.
- [ ] Add the RC34 saved-patch rollback runtime result.
- [ ] Add at least 3 screenshots: Analysis Plan, True Conflict 2/3/4, Compatibility patches selector.
- [ ] Optional short video: 2x -> Deploy -> 4x -> Deploy without rebuilding.
- [ ] Decide project license and include `LICENSE`.
- [ ] Include required third-party notices/licenses.
- [ ] Verify the distribution treatment of every bundled binary/resource.
- [ ] Keep legal wording factual: PMM operates on local game/mod files; do not promise that user redistribution/upload of third-party assets is universally permitted.
- [ ] State current platform target: Windows Steam Palworld.
- [ ] State PalSchema/UE4SS/Game Pass/Workshop as roadmap, not current support.
- [ ] Credit laredson and GPT-assisted development visibly.
- [ ] Credit upstream tools/projects and original mod authors.
- [ ] State that runtime-proven compatibility is tied to tested versions/hashes, not all future updates.
