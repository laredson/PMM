# PMM 1.3.1ModCreator

## Español

Programa portable: extrae el ZIP y ejecuta PMM.exe. Workspace se crea al arrancar; conserva tu Workspace anterior al actualizar.

- Creación asistida de mods mediante casos persistentes, investigación y candidatos PAK separados del despliegue.
- Puente MCP local y destinos diferenciados para Desktop, otros clientes MCP y Codex por consola.
- Vinculación con Desktop, apertura asistida de chats y estados basados en solicitudes recibidas, no solo ventanas abiertas.
- Casos independientes, selección protegida y recuperación de historial.
- Settings centraliza instalaciones, detección, ubicación manual y permisos reversibles. Las lecturas del historial de dependencias se realizan en segundo plano.
- Tutoriales de configuración en español e inglés.

El ZIP solo contiene PMM y sus dependencias redistribuibles incluidas. No contiene mods generados, partidas, archivos del juego, Unreal, Visual Studio ni paquetes offline de Wwise. Unreal/Wwise son opcionales y solo se requieren en los flujos que los utilizan.

Los candidatos deben revisarse y probarse antes de desplegarlos. La prueba del mod de inventario, el recorrido completo con cuenta Free y la ejecución visual automática siguen pendientes. No se garantiza compatibilidad de cualquier mod ni autonomía ilimitada del cliente de IA.

## English

Portable program: extract the ZIP and run PMM.exe. Workspace is created at runtime; preserve your previous Workspace when updating.

This release adds persistent mod-creation cases, the local MCP bridge, separate Desktop/external MCP/CLI destinations, assisted Desktop pairing and chat opening, independent case selection, centralized installation settings and reversible installation permissions. Dependency history loading runs in the background. Setup guides are available in Spanish and English.

The program-only ZIP includes PMM and its bundled redistributable dependencies. It excludes generated mods, saves, game files, Unreal, Visual Studio and Wwise offline packages. Optional authoring tools are required only for workflows that use them.

Built candidates are distinct from game-tested mods. Inventory-mod testing, the complete Free-account journey and automatic visual execution remain unverified.
