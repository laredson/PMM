PMM v1.2.1 — QUICK START

Normal use:
  Double-click PMM.exe

The portable application is intentionally clean:
  Engine/        native/runtime executables and managed dependencies
  Modules/       editable PMM PowerShell modules
  Resources/     UI, mappings and release metadata
  CKL/           Community Knowledge Library (stable, experimental and catalog)
  Documentation/ user documentation
  Workspace/     created automatically; all mods, builds, saves, logs, reviews and handoffs live here

No CMD/PowerShell console should flash during normal startup.

Workflow guidance:
  PMM highlights only the next useful stage: Import -> Analyze -> Build -> Deploy.
  Buttons return to the normal neutral style as soon as that step is already current.

Advanced runtime commands:
  Engine\PMMRuntime.exe self-test
  Engine\PMMRuntime.exe ui-native
  PMM.exe runtime-self-test

CKL is external data, not compiled into PMM. Stable knowledge can therefore be updated independently.
