# PMM 1.3.2 — Cases and compatibility repairs

## English

- Assistance now opens a persistent case. Choose a ZIP handoff, MCP or client from the case; keep its identity, evidence and history across those choices.
- Fixed the `Providers` exception when collecting handoff sources. Reanalysis preserves case edits and additional references.
- Settings can import a local `.usmap` for the installed game version. Extract Mapping104 and select **Import mappings** for Palworld 1.0.4, then run Analyze. Mapping104 is not bundled.
- Faster Mounts + RushRoar's exact known inputs can merge into the current 1.0.4 table while retaining the new fields and passive skills. This has structural/file validation; game behavior is not yet verified.
- Improved reference extraction for long Windows paths, interrupted publication recovery, partial-reader diagnostics and large-report logging.

EasyBreeding + NoCollision remains blocked on the changed 1.0.4 BreedFarm Blueprint. Open its case to inspect the evidence or supply a candidate. A previous successful merge does not establish compatibility with changed game files. Restart PMM after updating.

## Español

- La asistencia abre un caso persistente. Desde el caso puedes elegir un handoff ZIP, MCP o un cliente, conservando su identidad, evidencia e historial.
- Corregido el error `Providers` al recopilar las fuentes. Volver a analizar conserva tus cambios y las referencias adicionales del caso.
- Ajustes permite importar un `.usmap` local para la versión instalada. Extrae Mapping104, selecciona **Importar mappings** para Palworld 1.0.4 y vuelve a analizar. Mapping104 no está incluido.
- Los archivos exactos conocidos de Faster Mounts + RushRoar pueden fusionarse sobre la tabla de 1.0.4 conservando los campos y las pasivas nuevos. Validado en los archivos; todavía no dentro del juego.
- Mejoradas la extracción con rutas largas, la recuperación de publicaciones interrumpidas, la explicación de lecturas parciales y el registro de informes grandes.

EasyBreeding + NoCollision sigue bloqueado por el cambio del Blueprint BreedFarm en 1.0.4. Abre su caso para revisar la evidencia o aportar un candidato. Una fusión anterior no demuestra compatibilidad con archivos del juego que hayan cambiado. Reinicia PMM después de actualizar.
