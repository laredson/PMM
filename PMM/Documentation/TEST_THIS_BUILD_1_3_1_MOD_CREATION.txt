PMM 1.3.1 MOD CREATION PREVIEW - WINDOWS ACCEPTANCE
====================================================

1. Extract this ZIP into a new folder. Do not overwrite your stable folder.
2. If desired, copy your existing Workspace folder into this preview.
3. Confirm PMM starts normally and existing Analyze/Build/Deploy behavior is unchanged.
4. In Settings, confirm Vanilla Game Reference is Current; build it if needed.
5. Open AI & Help > AI assistance > New mod project...
6. Enter a title and description. Test both Save project and Create AI ZIP.
7. Confirm the ZIP opens in Explorer, the session remains after restarting PMM and nothing was uploaded.
8. Give the ZIP to an external AI. A query_game_reference request should produce a routed response ZIP.
9. Import that response. Prepare requested data and confirm only bounded GameReference data is present.
10. Import a valid PMM_MOD_CREATION_CANDIDATE_V1 response.
11. Inspect it, then press Build standalone PAK... and read the full warning.
12. Confirm the output PAK remains in the AIIO session and is NOT copied to Palworld's ~mods folder.
13. Run repak list on the PAK and confirm both the declared Pal/Content cooked files and:
      PMM/Metadata/created-with-pmm.json
14. Confirm mod-build.json contains:
      RequiredPublicDescription = This mod was created with PMM assistance.
15. Install/test the PAK only through an explicit separate action. Treat it as UNPROVEN until gameplay testing passes.

UI correctness checks:
- Confirm the top workflow row says SemiAUTO, the wide AUTO button occupies the center and CANCEL remains on the right.
- While AUTO is idle and enabled, confirm subtle sparkles cross the button; start AUTO and confirm the sparkles disappear until the workflow stops.
- Start a sufficiently long operation and confirm progress begins at 0, advances irregularly without exceeding worker-reported progress, catches up faster after a real backend advance and reaches exact 100 only on proven completion.
- Start with PMM Crystal saved, then reopen PMM. Confirm its colors are active immediately without pressing Apply changes.
- Open New mod project at Windows display/text scaling 100%, 125%, 150% and 200%. Confirm all labels, fields and the three bottom actions remain readable and reachable.
- Leave title or description empty and press Save project/Create AI ZIP. Confirm the dialog stays open, preserves typed text and focuses the missing field.
- Confirm the public save-management tab reads World Save (Guardado del mundo in Spanish).
- Create an AI ZIP, close Explorer, select that exchange in AI reception and press Open latest handoff. Confirm Explorer selects the exact latest request ZIP.
- Select a different theme or sound without pressing Apply changes, then toggle AUTO/Play, run Build or close PMM. Reopen PMM and confirm the un-applied appearance choice was not silently saved.

Negative checks:
- stale GameReference candidate is rejected;
- modified staged bytes are rejected;
- unexpected files, path traversal, executables and nested archives are rejected;
- an exact GameReference extraction request outside CREATE_MOD is rejected;
- no candidate import or build deploys, enables, publishes or promotes Knowledge automatically.
