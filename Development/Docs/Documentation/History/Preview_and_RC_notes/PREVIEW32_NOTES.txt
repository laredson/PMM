PalModMerger v1-preview32
========================

MAIN CHANGE
-----------
Preview31 correctly blocked FlyMode + WingPack on BP_WingGlider because the
existing relocatable writer could not prove a variable-size secondary .uasset
transplant. Preview32 adds a generic, no-rewrite proof instead of a Wing-specific
exception.

PMMCore 0.8.0: ContainedDeltaSuperset-v1
----------------------------------------
For the real Fly + Wing fixture:
- Fly has 12 Vanilla-relative BP_WingGlider .uexp hunks.
- Wing has 17.
- all 12 Fly hunks occur exactly in Wing at the same Vanilla coordinates/value.
- Fly's appended bCanFlyWithoutFuel metadata is prefix-contained by Wing.
- normalized export metadata/dependency sections remain compatible.

Therefore Wing is a proven real cooked superset for this exact asset family and
is preserved byte-for-byte. No UAsset.Write() path is introduced.

This adapter is generic and N-provider; it tries every provider as possible
anchor and contains no Fly/Wing asset-name logic.

SEMANTIC LAB v0.1
-----------------
Adds read-only symbol/effect evidence and a Knowledge/ regression base. It may
help explain likely behavior, but it never authorizes Build. Change-capsule
candidates are HEURISTIC_ONLY and non-selectable until dependency/control-flow
proof exists.

UNSUPPORTED / AI HANDOFF
------------------------
Unsupported review folders now generate AI_HANDOFF_<caseId>.zip with exact
cooked inputs, involved source PAKs, PMM reports, knowledge, instructions and a
return template. A returned PMM_MANUAL_SOLUTION_V1 ZIP can be explicitly
accepted as experimental. PMM validates exact case/input/provider hashes, safe
ZIP paths, topology, output hashes and AssetReader readability; gameplay remains
UNPROVEN until tested in Palworld.

UI
--
- source mods have enable/disable checkboxes;
- patches have their own panel;
- Analysis and Resolution panels collapse;
- unresolved decisions auto-open/highlight Resolution;
- Unsupported offers least-impact disable + Analyze and AI/manual tools;
- fixed bottom Build/Deploy/Restore controls;
- Remerge/Rebuild buttons removed.
