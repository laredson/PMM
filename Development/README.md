# Development

Everything that is not part of the normal portable PMM download lives here.

- `AI/` — current state and handoffs.
- `Docs/` — engineering, architecture, protocols, history and validation material.
- `Scripts/` — repository build/validation/CKL tools.
- `Source/` — native and managed source snapshot.
- `Tests/` — repository smoke tests.

The public release artifact must contain only the contents of the repository `PMM/` directory.

Start with `AI/CURRENT_STATE.md` before changing the project.
